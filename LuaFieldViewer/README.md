# Lua Field Viewer (MVP)

Android-приложение для просмотра значений полей из текстовых файлов
в формате сериализованных Lua-таблиц — `tool.txt`, `trends.txt`, `toolset.txt`,
`setting.txt` и других, которые создаёт StockRobot/QUIK-скрипты.

```
local a = {
   ['USDRUBF-SiZ6']={
      ['strategy202106']={
         ['minrest']=50000,
         ['trend']='short',
         ...
      },
   },
}
return a
```

## Возможности MVP

- **Файлы с сервера (HTTP)** — адрес (IP), порт, каталог и период
  автообновления задаются в настройках (шестерёнка на первом экране).
  Список файлов каталога перечитывается автоматически, открытый файл
  обновляется на лету: запрос идёт с заголовком `If-Modified-Since`,
  и при ответе `304 Not Modified` экран не перерисовывается.
- **Список файлов** — файлы каталога на сервере + встроенные образцы
  (tool.txt, trends.txt, toolset.txt, setting.txt) + любые файлы, выбранные
  через системный выборщик Android (SAF).
  Выбранные документы запоминаются между запусками; долгое нажатие — убрать
  из списка (файл на устройстве не удаляется).
- **Режим «Дерево»** — раскрываемая таблица «ключ → значение»:
  - таблицы раскрываются/сворачиваются (▸/▾), по умолчанию открыт верхний уровень;
  - массивы отображаются как `[1]`, `[2]`, …;
  - значения окрашены по типу (число / строка / bool / nil),
    числа показываются точно как в файле (`77762.0`, `-95.742660249554`);
  - бейджи `таблица · N полей` / `массив · N элементов`;
  - строка поиска — фильтр по ключам и значениям с полным путём узла;
  - тап по значению — копирование в буфер обмена;
  - сводка: количество полей, таблиц и глубина вложенности.
- **Режим «Текст»** — исходный текст файла (для больших файлов — первые
  200 000 символов с пометкой), с возможностью выделения и копирования.
- **Ошибки разбора** — понятное сообщение с номером строки/столбца и фрагментом
  + переход к просмотру файла как текста.
- Кодировка файла определяется автоматически: UTF-8 (в т.ч. с BOM),
  UTF-16, windows-1251.

## Сборка

1. Открыть папку `LuaFieldViewer` в **Android Studio** (Hedgehog или новее) —
   Studio сама подтянет Gradle 8.9 через wrapper и SDK (compileSdk 35).
2. Дождаться синхронизации и запустить `Run ▶` на устройстве/эмуляторе
   (Android 8.0+).

Сборка из командной строки (нужны JDK 17+ и Android SDK):

```bash
# Windows
gradlew assembleDebug
# Android Studio должна создать local.properties со строкой sdk.dir=...
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Формат данных (что поддерживает парсер)

- обёртка `local a = { … }` + `return a` (также допустимо `return { … }`);
- ключи: `['строка']`, `["строка"]`, `[1]`, «голые» `name=`;
- значения: числа (включая `-95.74`, `1e-3`, `.5`, hex `0x1F`),
  строки `'…'`/`"…"` с escape-последовательностями, `true`/`false`/`nil`,
  вложенные таблицы (любая глубина);
- разделители `,` и `;`, комментарии `--` и `--[[ … ]]`.

Не разбираются (и не встречаются в этих файлах) арифметические выражения,
вызовы функций, переменные-ссылки: файлы — это данные, а не исполняемый код.
Логика парсера покрыта unit-проверками на реальных файлах репозитория
(tool.txt — 23 594 поля / 1 587 таблиц, trends.txt — 8 917 полей / 1 065 таблиц).

## Ограничения MVP и планы следующих версий

- интерфейс и наборы отображаемых полей будут конкретизированы в следующих
  версиях (сейчас — произвольное дерево всех полей файла);
- сервер читается по HTTP без авторизации (логин/пароль — в следующих версиях);
- автообновление работает, пока экран открыт (в фоне приложение ничего не читает);
- режим «Текст» ограничевается первыми 200 000 символов;
- поворот экрана перечитывает файл (кэша ещё нет);
- для файлов больше единицы мегабайта разбор может занять заметное время —
  показывается индикатор загрузки.
